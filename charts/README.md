# charts

Generate publication-quality charts as SVG or PNG files using [charts-cli](https://github.com/Michaelliv/charts-cli) and ECharts JSON configs — bar, line, pie, scatter, radar, funnel, gauge, treemap, boxplot, heatmap, candlestick, and sankey. No browser required.

The skill itself is [`SKILL.md`](SKILL.md). All content lives in that one file; there are no accessory reference files.

## What it covers

- **Installation and core workflow** — from data to rendered chart file.
- **CLI reference** and output size guidelines.
- **Design standards** — a consistent, legible visual system.
- **Chart recipes** — ready configs for every supported chart type.
- **Themes, mixed/combo charts, and data-transformation patterns.**
- **Chart-type selection guide**, agent instructions, and a validation checklist.

## Requirements

Node.js 18+, then install once:

```bash
npm install -g charts-cli
```
